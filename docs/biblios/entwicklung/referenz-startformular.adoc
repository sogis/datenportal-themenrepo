== Grundsatz

Das Startformular ist fix. Es wird nicht mehr aus YAML- oder Datensatzkonfiguration im Themenrepo zusammengesetzt.

== Unterstützte Felder

[cols="1,3",options="header"]
|===
| Feld | Bedeutung

| `ORGANISATION`
| Aus den gültigen Organisationen im Themenrepo abgeleitet.

| `DATASET`
| Aus den erkannten Datensatzordnern und Datenblättern der Organisation abgeleitet.

| `METADATA_FILE`
| Upload-Feld für Metadaten.

| `DATA_FILE`
| Upload-Feld für Daten.

| `COMMENT`
| Freitextkommentar zur Lieferung.

| `SERIES_ID`
| Nur sichtbar, wenn das Datenblatt eine `DatasetSeries` beschreibt.
|===

== Keine GUI-Konfiguration im Themenrepo

Das Themenrepo kann keine zusätzlichen Formularfelder definieren.
